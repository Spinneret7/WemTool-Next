# WemTool Next
Introducing a new version of the wem tool which was made by Masquerade from Kaos Krew even though the tool worked properly it had a few problems and was made using bat2exe, so this is a ground up remake of that same tool using C and using the same tools and compressors as the original wem tool! 

## Usage
This version of wemtool has 2 separate exe being wemenc and wemdec, run the particular tools without any arguements it just needs .wem files to be present in the same folder the exe itself is.
Though please note, this tool should be only used when there is wwise vorbis aka ogg in the wem files, It will leave the ones containing wav files and non compressible vorbis files as it is.

## Compile
Run Build.bat and Gcc is needed for this to compile.
